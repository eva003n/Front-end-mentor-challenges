# Brief
Your challenge is to build Frontpage, a content aggregator that pulls RSS and Atom feeds into a single, well-designed reading dashboard. There's no Figma file for this challenge — you'll make all the design decisions yourself.

We provide a brand kit with design tokens, sample data with curated RSS feeds, and detailed specs in the starter code. You can use any tools you like to help you complete the challenge.

We provide the data in a local JSON file, allowing you to populate the content on first load in "guest mode". We recommend building this project as a full-stack application, though.

Your users should be able to:

- Add, organize, and manage RSS/Atom feed subscriptions across custom categories
- Browse, search, and bookmark articles from all their feeds in one place
- Read articles in an in-app reader view or open the original source
- Track read and unread state across feeds
- Import and export subscriptions using OPML
- Sign up for an account or try the app as a guest with pre-loaded content
- See a landing page that communicates the product's value
- View the optimal layout for the app depending on their device's screen size

These features have no spec — you design them:

- **Content discovery and onboarding:** How do new users find feeds to follow?
- **Digest view:** How do users catch up on what they missed?
- **Layout customization:** What layout options can users choose from?

Download the project and go through the README.md file. This will provide further details about the project and help you get set up.

## 💡Ideas to test yourself
1. Add keyboard shortcuts and a command palette for power users
2. Use AI to summarize articles or generate weekly highlight digests
3. Add offline reading support and ship as an installable PWA
4. Let users receive newsletters via a unique email address alongside their feeds
5. Track reading habits and display analytics like streaks and activity heatmaps
6. Build customizable reading preferences for font size, line height, and contrast
